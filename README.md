# Letter For Friends
Like passing notes in class

## Behavior

- New letters start as drafts with a randomly generated passcode and an expiration one calendar month from creation.
- You can set an expiration in your local time or mark a letter permanent. An expired letter is unavailable to recipients; extending its date makes it available again if it was not removed.
- Publishing allows anyone with its passcode to read from any device. Changing the passcode invalidates existing reader sessions.
- Before an expiring letter expires, any reader can make it permanent for everyone with access. The master can assign a new expiration later.
- Each active letter can also have a passwordless NFC URL. The master workspace can create, copy, rotate, or revoke it. Rotating or revoking the URL invalidates existing reader sessions; the passcode remains available.
- Recipients can remove their access. You can also remove access. Removal is permanent and cannot be undone, including by the master. You retain a read only copy.
- Uploaded files may be up to 100 MB each and are limited to JPEG, PNG, WebP, GIF, MP4, WebM, MP3, M4A, WAV, PDF, and plain text.
- Login attempts are limited per IP and mode, and messages and files are rechecked on each request.

The NFC tag is a convenient entrance, not proof that someone tapped it. Anyone who learns a valid passcode can open the corresponding letter.
